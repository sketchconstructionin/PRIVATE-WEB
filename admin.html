Connecting Real-time Google APIs

This analytics interface is pre-wired to load your site's indexing performance. To stream live data directly from your Google Analytics 4 properties and Google Search Console property into this panel:

  1. Enable the Google Analytics Data API v1beta and Google Search Console API in your Google Cloud Developer Console.
  2. Create a Service Account, generate a **JSON credentials key**, and upload it as `google-service-account.json` inside your backend `whatsapp-api/` directory.
  3. Add your GA4 property ID (`GOOGLE_GA4_PROPERTY_ID`) to your `.env` variables list.
Until the JSON credentials key is uploaded, this panel displays cached performance metrics based on GTM site logs and standard indexes.
